# PF poker для Android

Это исходный Android-проект, НЕ готовый APK. В текущей среде нет Android SDK, и доступ к загрузкам Google заблокирован. Компиляция и запуск на телефоне не проверены.

Встроена текущая тренировочная версия PF poker: лобби, Texas Hold’em против бота, локальные клубы и история. Игра загружается из пакета приложения, а не с приватного сайта. Интернет-разрешение не требуется. Сетевой игры и денежных ставок нет. Данные веб-версии автоматически не переносятся. Нужен Android 8.0+ и современный Android System WebView.

## Получить APK через GitHub (можно с телефона)

1. Распакуйте архив. Создайте свой пустой приватный репозиторий GitHub.
2. Загрузите СОДЕРЖИМО папки PF-poker-Android в корень репозитория. Обязательно включите скрытую папку `.github/workflows`.
3. Откройте Actions → Build PF poker APK → Run workflow. При необходимости разрешите Actions для репозитория.
4. После успешной сборки откройте её результат. В Artifacts скачайте PF-poker-APK и извлеките PF-poker.apk.
5. Откройте APK на Android. Если система запросит разрешение на установку для браузера/файлового менеджера, разрешите его для установки этого файла.

Сборка выдаёт подписанный отладочным ключом тестовый APK. Для публикации и обновлений понадобится постоянный release-ключ. Отладочный ключ нового запуска GitHub может отличаться: обновление поверх прежнего APK тогда не установится. Не удаляйте старое приложение, если хотите сохранить его локальные данные.

## Локальная сборка на компьютере

Требуются JDK 17, Gradle 8.13, Android SDK platform 35 и build-tools 35.0.0. Укажите SDK через ANDROID_HOME или local.properties. В корне проекта выполните:

    gradle :app:assembleDebug

Результат: app/build/outputs/apk/debug/app-debug.apk

Совместимость выбранных версий: https://developer.android.com/build/releases/agp-8-13-0-release-notes

Termux не требуется. В архиве нет скрипта установки Android SDK для Termux: стандартные SDK-инструменты для Linux не рассчитаны на непосредственный запуск в Android/ARM.
